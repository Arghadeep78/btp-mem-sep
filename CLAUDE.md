## 2. Flowsheet

Screenshots of the GUI flowsheets were captured on 2026-10-05, **before** the fixes (the METH screenshot has no compressor train):
[global](docs/flowsheets/flowsheet_global.png) · [METH](docs/flowsheets/flowsheet_METH_hierarchy.png).

### Global section (anaerobic digestion + gas cleanup)
```
BIOMASS (8.5 t/d, 23 °C) ─┐
WATERIN (13 t/d water)  ──┴─ MIX1 ─ FEED ─ RSTOIC (hydrolysis, 55 °C) ─ 5 ─ B1 RCSTR (55 °C, 15 d, 2-phase)
                                                                           ├─ LIQUID (digestate, out)
                                                                           └─ BIOGAS ─ FLASH (25 °C,1 atm)
                                                                                         ├─ H2O1 (out)
                                                                                         └─ GAS ─ H2S-SEP ─ GAS2 ─ NH3SEP ─ GAS3 ─ $C-1 ─► METH.GAS
                                                                                                    └─ H2S          └─ NH3 (out: everything except CO2/H2/CH4/CO)
```
- **NH3SEP is really a "keep only CO2, H₂, CH₄, CO" splitter**: GAS3 gets fraction 1 of CO2, HYDROGEN, METHANE, CO and 0 of everything else, water included. So the METH hierarchy only ever sees these 4 components; CO is ≈ 0.
- B1: residence time 15 d. Results show a condensed-phase volume of **≈ 320 m³** (the design liquid volume); the 17 000–19 600 m³ total is vapour headspace, which the liquid-phase reactions don't use. No change needed (Session 3.2).

### Hierarchy `METH` (upgrading + pyrolysis), `SOLVE METHOD=SM`
```
GAS ─ PURGAS (SEP) ─ GAS2 ─ COMP1 (3.18 bar) ─ COOL1 (30 °C) ─ COMP2 (10 bar) ─ COOL2 (30 °C) ─ GAS2C ─ MEMB1 (ACM Zeo_real)
        └─ WASTE (always 0)                                                                                ├─ PER (1 bar, out)
                                                                                                           └─ RET (10 bar) ─ FLASH3 (30 °C, 1 bar) ─ PROD4 ─ HEAT2 (790 °C, 1 bar) ─ PYROIN ─ CH4PYRO (RPLUG) ─ FINPROD
                                                                                                                                └─ H2O-2 (out)
```
- PURGAS sends fraction 1 of WATER/CO2/H₂/CH₄/CO/CARBON to GAS2, so WASTE is always empty (by design; parked: C9).
- Compression (Session 5): two isentropic COMPR stages (η = 0.75) with HEATER coolers to 30 °C, about 5.5 kW total. A 2× COMPR + 2× HEATER train is used because MCOMPR stage specs were not honoured when written as `.bkp` text. FLASH3 and HEAT2 already set 1 bar, so no letdown valve is needed.
- CH4PYRO: L = 18.9 m, D = 0.378 m, T-spec 790 °C, catalyst 24.668 kg (ρ = 1500 kg/m³), vapour phase, integration tolerance 1E-4. Reactions R-1 (CH₄ → C(s) + 2 H₂) and R-2 (CO₂ + H₂ → CO + H₂O).
- Global flash maximum iterations = 100 (Setup → Simulation Options). The H2S-SEP flash of GAS2 needs about 37.

### Property methods
- Global: `NRTL` (secondary `PENG-ROB`), `ESTIMATE ALL`, stream class `MIXCISLD` (CARBON is CISOLID).
- **Henry components `HC-1` = CO2, METHANE, HYDROGEN, H2S, CO**, set globally; METH inherits it (Session 3.1).
- METH: `NRTL` with `FREE-WATER=STEAM-TA SOLU-WATER=3 TRUE-COMPS=YES`. There is no CHEMISTRY block, so these options do nothing (parked: C12).
- 22 databanks enabled (APV140 PURE40/AQUEOUS/SOLIDS/…, NIST-TRC, AP-EOS).

### Components (62)
Water; glycerol; LCFAs (OLEICACI, LINOLEIC, **PALM = palmitic acid C16H32O2**, databank `N-HEXADECANOIC-ACID`); sugars (DEXTROSE, GLUCOSE, XYLOSE); VFAs (ACETI-AC, PROPI-01, ISOBU-01, ISOVA-01, ACETATE); 17 amino acids; biomass `C5H7NO2`; gases (CO2, HYDROGEN, **METHANE** (ID is `METHANE`, not `CH4`), CO, H2S, NH3, CH4S); aromatics (BENZENE, PHENOL, INDOLE, FROMAMID, FURFURAL); ions (H+, OH-, NH4+, HCO3-, CO3-2, HS-, H2CO3); polymers (CELLULOS, HEMECELL, STARCH, TRIOLEIN, TRIPALM, SN-1--01, SN-1--02); user-defined PROT, KERATIN, INERT (PC-USER); CARBON (CISOLID); ETHANOL.
The ions never get flow because there is no chemistry. They act as placeholders that the calculators read (and get 0). NH4+ is defined with formula H3N, i.e. it is a neutral copy of NH3.

| `CO2METH`, `COMETH`, `RWGS` | LHHW | **Defined but not used by any block** |

### Calculator blocks (read B1 outlet `LIQUID`, write rate constants; converged by a tear loop)

| Calculator | Writes PRE-EXP of | Notes |
|---|---|---|
| AMINODEG | AMINOACI 1–23 (not 3, 12) | Computed pH ≈ 7 (H⁺ never has flow) |
| DEXTDEG / GLYCDEG | ACIDOGEN 1 / 2 | |
| OLEICDEG / PROPDEG / BUTYDEG / VALEDEG / LINODEG / PALMDEG | ACETOGEN 1 / 2 / 3 / 4 / 5 / 6 | `PH = 6.5` hard override, so pH inhibition is off |
| METHAN | METHAN 1 | `PH = 6.5` override; uses the ADM1 pH 6–7 window, no H₂ term (correct for acetoclastic methanogens) |

- Since Session 4 the calculators read concentrations from **`LIQUID` (B1 outlet = reactor concentrations)**, not stream 5. They run as import/export loop members; Aspen tears their exported PRE-EXP values with a damped Wegstein (`TEAR-VAR = YES`, `WEG-MAXIT = 200`, `WEG-QMAX = 0.5`).
- `VOLFLOW` is still `STDVOL-FLOW` (Aspen rejects `VOL-FLOW` for a STREAM-VAR here).
- LCFA inhibition uses the total LCFA pool (OLEICACI + LINOLEIC + PALM) in BUTYDEG, DEXTDEG, GLYCDEG, METHAN, PROPDEG and VALEDEG.
- Pattern: Monod substrate term × NH₃/LCFA/HAc/H₂ inhibition × Arrhenius-like correction around T0 = 55 °C. B1 runs at exactly 55 °C, so the temperature terms are currently 1.

## 5. ACM model `Zeo_real` (current)

Source: `files/zeo_real.acmf` = `CustomModeling/CustomModeling.acmf` inside the ATMLZ (identical). Design notes and verify table: [06_membrane_acm_rewrite.md](docs/fixes/phase1/06_membrane_acm_rewrite.md).

- **Well-mixed membrane, one balance per component over the whole `ComponentList`.** Permeating set `PermSet = ["CO2","HYDROGEN","METHANE"]` (Aspen IDs); every other component has `nP = 0` and stays in the retentate.
- Flux: `nP(c) = Pi(c)·A·1e5·(Feed.P·Retentate.z(c) − Permeate.P·Permeate.z(c))·3.6` [kmol/h], with port P in bar.
- Permeances (DDR zeolite, 297 K; Yang et al., J. Membr. Sci. 2016), mol/(m²·s·Pa): CO₂ 2.1e-7, H₂ 1.36e-7, CH₄ 3.03e-9. **A = 5 m²**, `dP_ret = 0`.
- `Retentate.T = Permeate.T = Feed.T`, `Retentate.P = Feed.P − dP_ret`, enthalpy from `pEnth_Mol`. No `max`/`min`.
- Aspen block specs (`METH.MEMB1`): `PERMEATE.P` fixed (1 bar) and **`PERMEATE.V` fixed = 50** (added in edit-6). The old `T` REALPARAM (298.15) was removed.

**Latest results (2026-10-06 run):**

| Stream | F (kmol/h) | P (bar) | CH₄ | CO₂ | H₂ |
|---|---|---|---|---|---|
| GAS2C (feed) | 2.268 | 10 | 58.7 % | 40.9 % | 0.32 % |
| RET (to pyrolysis) | 1.689 | 10 | **76.4 %** | 23.4 % | 0.21 % |
| PER | 0.579 | 1 | 7.1 % | 92.2 % | 0.63 % |

CH₄ recovery to RET ≈ 96.9 %; CO₂ removed ≈ 57.5 %. Tuning knobs: `A` (3–10 m²) and feed pressure. For a high-selectivity sensitivity case use Π_CO2 = 4.2e-7, Π_CH4 = 1.2e-9 (Himeno 2007).

**After any ACM change:** recompile, re-export the ATMLZ, keep the desktop `.acmf` identical to it, and log both files in the edit log.
